# نکته درباره این پوشه

فایل‌های `tv.png`, `fridge.png`, `washing.png` در این پوشه فقط **تصاویر نمونه/جاگیرنده** هستند
که مطابق ساختار درخواستی پروژه اضافه شدند.

⚠️ سایت واقعاً از این فایل‌ها استفاده نمی‌کند. عکس واقعی هر محصول از طریق پنل مدیریت
آپلود می‌شود و در بک‌اند (پوشه‌ی `uploads/` سمت سرور) ذخیره می‌شود، و آدرس آن به‌صورت
پویا (مثل `http://localhost:4000/uploads/xxxx.jpg`) در دیتابیس ثبت و از آنجا نمایش
داده می‌شود — نه از این پوشه‌ی استاتیک فرانت‌اند.

اگر می‌خواهید محصولات از قبل عکس داشته باشند، ساده‌ترین راه این است که از پنل مدیریت
(`admin.html`) وارد شوید و برای هر محصول از تب «محصولات» عکس آپلود کنید.
